# Employee Management System — Angular Frontend

An Angular application for managing employee records through a REST API.

## Technologies
- Angular
- TypeScript
- HTML and CSS

## Prerequisites
- Node.js and npm

## Installation

```bash
npm install
```

## Run the application

```bash
npx ng serve
```

Open http://localhost:4200 in your browser.

## Backend Configuration
Ensure the Spring Boot backend is running and the frontend API service is configured with the correct backend URL.
